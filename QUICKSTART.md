# Quickstart

Load the prototype locally. The dev server does not call an LLM, so no API key is required.

From the repository root:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

Stop the server with Ctrl+C.

Run the configuration kernel tests without starting the dev server:

```bash
pnpm test
```
